
# To-Do List Application

## Project Description
A simple console-based To-Do List Application developed using Python.

## Features
- Add new tasks
- View all tasks
- Remove tasks
- Save tasks in a text file
- Load saved tasks when the program starts

## Technologies Used
- Python
- Visual Studio Code

## Files
- todo.py - Main Python program
- tasks.txt - Stores saved tasks

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run: python todo.py
